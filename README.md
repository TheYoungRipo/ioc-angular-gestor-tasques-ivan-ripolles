# Gestor de tasques

## Autor/a
Ivan Ripolles Cervera

## Descripció
Aplicació web desenvolupada amb Angular per a gestionar les tasques diàries de manera eficient.

## Versions utilitzades
- Node.js: 24.21.0
- npm: 11.19.0
- Angular CLI: 22.2.2
- Git: 2.56.0

## Com crear i executar el projecte
1. Instal·lació de dependències: 
   npm install

2. Execució del servidor de desenvolupament local:
  ng serve

L'aplicació estarà accessible a `http://localhost:4200`.
